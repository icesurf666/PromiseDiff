| Asset | Intended placement |
|---|---|
| `promise-diff-hero.svg` | Article hero / social card |
| `verification-flow.svg` | After “What I built” |
| `verdict-matrix.svg` | After the four outcomes table |
| `evidence-gate.svg` | After the hybrid-system explanation |
| `benchmark-results.svg` | Benchmark section |
| `security-boundaries.svg` | Implementation or limitations section |
| `progresscut-demo.gif` | Short product walkthrough in the Demo section |

For DEV.to, upload each SVG (or a rendered PNG copy) and replace every local `assets/<filename>` image link in `DEVTO_SUBMISSION.md` with the URL DEV assigns to the upload. For the personal site, place the files under `public/writing/promise-diff/` and reference them by `/writing/promise-diff/<filename>`.
